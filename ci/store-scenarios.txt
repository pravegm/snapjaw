# Run by .github/workflows/store.yml: ci/store-capture.sh phone → ci/screenshots.sh (SCENARIOS=this file,
# SCENARIO_FILTER='^P[0-9]', WAIT_FREEZE=1) on the iPhone 18 Pro Max (6.9", 2868 x 1320) and the iPhone 18 Pro (6.3",
# 2622 x 1206), then ci/store-set.sh captions them (ci/store-frame.swift) into <set>/store/ with a MANIFEST. The Duo
# set lives in ci/duo-store-scenarios.txt. Names are zero-padded (P01–P10) so the upload folder sorts in frame order,
# and they are exactly the file names docs/appstore/asc-metadata.json lists (P01-book-hero … P10-first-bite).
#
# name|demo args (Snap/App/DemoMode.swift; keys in design/ROUND-1.md "Demo mode")|seconds to wait|caption: headline / sub-line|expect (extra log regex)|frame
#  - wait: a freezeOn=<tag> scenario waits for the app's "SNAP-T freeze <tag>" line instead (at least this long, at
#    least 60 s), then 2 s. freezeAfter=<s> next to freezeOn means the moment only counts after s seconds of play (the
#    light and the bugs have settled; screenshots.md's "freeze delay" ask).
#  - caption: `*word*` is the ONE gold-swash word; " / " starts the sub-line. Headline ≤ 30 characters (without the
#    asterisks) and ≤ 7 words. No "|". store-frame.swift REJECTS smash, squish, squash, splat, kill, slam, "Fold to"
#    and the competitor's name; store-set.sh flags flat, "shut" on its own (not "a little shut"), quick, fast, prices
#    and "#1".
#  - frame: flat (default) or book:<Duo scenario> = the book-pose composite of that Duo capture (store-frame --book);
#    P01's own capture here is only the fallback if the Duo capture is missing (then P01 is FLAGGED: never upload a
#    flat P01 without telling the founder).
#  - No fold here: every iPhone frame must log an unfolded canvas with the HUD on the right
#    ("SNAP-T canvas WxH fold=0 hudLeft=0", required by the workflow), and the hints say "Tap to snap". A pilot plays
#    every play frame (the phone sim has no hinge).
#  - Seeds, waves and pilots are the ones proven in ci/scenarios.txt and on the Duo (duo run 40603497021: crowd at
#    wave 6, feast count=5 at wave 8, bee at wave 15, all with the perfect pilot), not screenshots.md's first guesses
#    (mode=attract, seed 11): feed mode shows the real snaps row, so the economy on screen is the real one.

# scored try a day; First Bite runs on the first go. If any of these change, change the caption.
