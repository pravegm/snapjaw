# CI screenshot scenarios (ci/screenshots.sh on the "iPhone 18 Pro" simulator: no hinge, so the UI turns landscape by
# itself and the trap is tap-to-snap unless a pilot= drives it or closure= holds it).
# name|demo args (-snapDemo, keys in design/ROUND-1.md "Demo mode")|wait s|caption (what the frame should show)|expect
#  - wait: a freezeOn=<tag> scenario waits for the app's "SNAP-T freeze <tag>" line instead (up to max(wait, 60) s),
#    then 2 s; a freezeAfter=<s> one waits for any "SNAP-T freeze" line the same way. It is captured anyway (and
#    flagged no-freeze in captures.tsv) if the line never comes.
#  - expect: optional extended regex the app log must contain at capture time (reported, never fatal).
#  - No "|" inside a field, the expect regex included (it would split into a bogus extra column).
#  - Names are zero-padded so the artifact sorts in reading order.
#  - The app icon is not a scenario: ci.yml renders it in its own step (screen=icon → app-icon-1024.png).
#  - The Duo's real-hinge frames, the cover display and the book-pose card live in ci/duo.sh (duo.yml).
#  - Long waits (lastSnap, tired, results) are for a novice pilot spending 10 snaps; a missed freeze is captured anyway.
#
